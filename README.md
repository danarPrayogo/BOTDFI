## 📌 Tentang Project

> 💡 **MaPen UMKM** adalah aplikasi Android yang dirancang untuk membantu pelaku usaha mikro, kecil, dan menengah dalam mengelola bisnis secara lebih efektif dan efisien.
>
> Dengan fitur pencatatan transaksi, manajemen produk, laporan penjualan, serta **Smart Business Assistant berbasis AI**, pengguna dapat memperoleh insight bisnis secara otomatis.
